# Заявки техподдержки

Практическое занятие №1. Middleware и шаблонизаторы. Ветка `pz21`.

Сервер на Express отдаёт страницы через EJS. Заявки лежат в массиве в памяти: после перезапуска остаются только пять исходных записей.

## Запуск

```bash
cd itivp_pz
npm install
npm start
```

Откройте http://localhost:3000

Если порт 3000 уже занят, запустите так:

```bash
PORT=3001 npm start
```

и откройте http://localhost:3001

## Страницы

| Адрес | Что открывается |
| --- | --- |
| `/` | Список заявок от имени гостя |
| `/?auth=1` | Тот же список от имени оператора |
| `/item/1` | Карточка заявки |
| `/add` | Без `?auth=1` перенаправляет на вход |
| `/add?auth=1` | Форма новой заявки |
| `/login` | Пояснение, как войти |
| `/no-page` | Страница 404 |
| `/cause-error` | Страница 500, текст ошибки в консоли |

## Ограничения полей формы

| Поле | Требование |
| --- | --- |
| Тема | от 3 до 100 символов, без переносов строк |
| Описание | от 10 до 1000 символов, переносы строк разрешены |
| Автор | от 2 до 60 символов, без переносов строк |
| Статус | Новая, В работе, Решена, Закрыта |
| Приоритет | Низкий, Средний, Высокий |

Пробелы по краям обрезаются до проверки длины. Управляющие символы запрещены. Тело запроса не больше 32 КБ.

Параметр `?auth=1` нужно сохранять в адресе, пока хотите оставаться оператором. Ссылки в шапке подставляют его сами.
